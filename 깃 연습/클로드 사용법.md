# 클로드(Claude Code) 사용법

Claude Code는 터미널에서 대화하며 코딩·파일 작업·자동화를 맡길 수 있는 Anthropic의 AI 도구다.
CLI 외에 데스크톱 앱(Mac/Windows), 웹(claude.ai/code), VS Code·JetBrains 확장으로도 쓸 수 있다.

---

## 1. 시작하기

```bash
cd 작업할폴더   # 작업할 폴더로 이동
claude          # Claude Code 실행
```

- 실행한 폴더가 **작업 폴더**가 된다. 클로드는 이 폴더의 파일을 읽고 수정한다.
- 처음 한 번 로그인하면 이후에는 바로 쓸 수 있다.

---

## 2. 기본 사용법

평소 말하듯이 요청하면 된다.

```
이 폴더 구조 설명해줘
photo_edit.py에 흑백 변환 기능 추가해줘
깃 연습 폴더 만들고 GitHub에 올려줘
```

### 잘 시키는 요령
- **구체적으로**: "고쳐줘"보다 "로그인 버튼을 눌러도 반응이 없어, 원인 찾아서 고쳐줘"
- **파일을 짚어주기**: `@파일명`으로 특정 파일을 대화에 포함시킬 수 있다
- **결과물 형태 말하기**: "표로", "md 파일로", "PNG로"
- **한 번에 하나씩**: 큰 작업은 단계를 나눠서 요청

---

## 3. 자주 쓰는 키와 기호

| 입력 | 기능 |
|---|---|
| `Enter` | 메시지 보내기 |
| `Esc` | 클로드가 작업 중일 때 멈추기 |
| `Esc` 두 번 | 이전 메시지로 되돌아가기 |
| `Shift + Tab` | 권한 모드 전환 (일반 / 자동 수정 허용 / 계획 모드) |
| `@파일명` | 파일을 대화에 첨부 |
| `! 명령어` | 내가 직접 터미널 명령 실행 (예: `! gh auth login`) |
| `/` | 슬래시 명령어 목록 열기 |

---

## 4. 주요 슬래시 명령어

| 명령어 | 기능 |
|---|---|
| `/help` | 도움말 |
| `/clear` | 대화 내용 초기화 (새 작업 시작할 때) |
| `/compact` | 긴 대화를 요약해서 공간 확보 |
| `/init` | 프로젝트 설명서 `CLAUDE.md` 자동 생성 |
| `/model` | 사용할 모델 변경 |
| `/config` | 설정 열기 |
| `/resume` | 이전 대화 이어서 하기 |
| `/스킬이름` | 만들어 둔 스킬 실행 (예: `/카드제작기`) |

---

## 5. 클로드를 내 방식대로 만들기

### CLAUDE.md – 프로젝트 설명서
프로젝트 폴더에 `CLAUDE.md`를 두면 클로드가 매번 먼저 읽는다.
"답변은 한국어로", "커밋 메시지는 한글로" 같은 규칙을 적어두면 된다.

### 스킬 (Skills) – 반복 작업 레시피
`.claude/skills/스킬이름/SKILL.md`에 작업 방법을 적어두면, 관련 요청이 왔을 때 클로드가 그 방법대로 일한다.

이 저장소에 있는 스킬:
- `photo-edit` – 사진 밝기·색감 보정, 크기 변경, 비율 자르기
- `검색정리기` – 웹 최신 자료 검색 후 카드뉴스용으로 정리
- `카드제작기` – 카드뉴스 PNG 제작
- `플라` – Playwright로 브라우저 조작

### 에이전트 (Agents) – 전문 담당자
`.claude/agents/이름.md`에 역할을 정의하면 그 일을 따로 맡길 수 있다.

이 저장소에 있는 에이전트:
- `웹구조` – 웹페이지 구조·기능 분석
- `카드` – 자료 조사부터 카드뉴스 제작까지

### MCP – 외부 도구 연결
브라우저(Playwright), Gmail, 구글 캘린더, 노션 등 외부 서비스를 연결해서 클로드가 직접 다루게 할 수 있다.

## 6. Git과 함께 쓰기

클로드에게 말로 시키면 Git 작업도 대신 해준다.

```
지금까지 바뀐 거 커밋하고 푸시해줘
AI 레포지토리 상태 확인해줘
새 브랜치 만들어서 작업해줘
```

직접 하려면:
```bash
git add .
git commit -m "변경 내용"
git push
```

---

## 7. 주의할 점

- 클로드가 파일을 수정하거나 명령을 실행하기 전에 **권한을 물어보면 내용을 확인하고** 허락하자.
- 비밀번호·API 키 같은 민감한 정보는 저장소에 올리지 않는다.
- 결과가 이상하면 `Esc`로 멈추고 다시 설명하면 된다.
- 대화가 너무 길어지면 `/compact`나 `/clear`로 정리하자.
