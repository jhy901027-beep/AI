# photo-edit (미니 포토샵)

요청: $ARGUMENTS

스크립트: `C:\Users\SBS\ai\.claude\skills\photo-edit\scripts\photo_edit.py`
필요 라이브러리: Pillow (`python -m pip install pillow`)

## 실행
```powershell
$env:PYTHONIOENCODING='utf-8'; python "C:\Users\SBS\ai\.claude\skills\photo-edit\scripts\photo_edit.py" <사진 또는 폴더> [옵션]
```

| 옵션 | 값 | 설명 |
|---|---|---|
| `--brightness` | 배율 (기본 1.0) | 1.2 = 20% 밝게, 0.8 = 20% 어둡게 |
| `--contrast` | 배율 (기본 1.0) | 1.2 = 또렷하게, 0.8 = 흐릿하게 |
| `--saturation` | 배율 (기본 1.0) | 0 = 흑백, 1.3 = 선명한 색 |
| `--warmth` | -100~100 | 색온도. +면 따뜻하게(주황), -면 차갑게(파랑). 30 안팎이 자연스러움 |
| `--hue` | 각도 -180~180 | 색상환 회전. **모든 색이 함께 돌아가므로** 따뜻/차갑게 용도가 아니라 색을 바꾸는 특수 효과용 |
| `--ratio` | `1:1` `4:5` `9:16` | 가운데를 기준으로 잘라 비율 맞춤 |
| `--width` / `--height` | 픽셀 | 하나만 주면 비율 유지, 둘 다 주면 그 크기로 |
| `--scale` | 퍼센트 | 50 = 절반 크기 (`--width`와 함께 못 씀) |
| `--out` | 폴더 | 결과 폴더. 기본은 입력 위치의 `보정결과\` |
| `--recursive` | | 폴더 입력 시 하위 폴더까지 (폴더 구조 유지) |

처리 순서는 **비율 자르기 → 크기 변경 → 밝기 → 대비 → 채도 → 색온도 → 색조**. 자른 뒤 줄이므로 `--ratio 4:5 --width 1080`이면 정확히 1080×1350이 나온다.

## 말로 된 요청을 옵션으로 바꾸기
사용자는 숫자 대신 느낌으로 말하는 경우가 많다. 과하면 사진이 망가지므로 처음엔 약하게 적용하고, 결과를 보고 더 원하면 올린다.

| 요청 | 옵션 |
|---|---|
| 조금 밝게 / 많이 밝게 | `--brightness 1.1` / `1.3` |
| 또렷하게, 선명하게 | `--contrast 1.15` |
| 색감 진하게 / 차분하게 | `--saturation 1.25` / `0.8` |
| 흑백 | `--saturation 0` |
| 따뜻하게 (노랑·주황 쪽) | `--warmth 30` |
| 시원하게, 차갑게 (파랑 쪽) | `--warmth -30` |
| 색을 확 바꾼 특수 효과 | `--hue 30` 이상 |
| 인스타 피드 / 정사각형 / 스토리·릴스 | `--ratio 4:5` / `1:1` / `9:16` (+ 보통 `--width 1080`) |
| 용량 줄이기, 웹용 | `--width 1600` 또는 `--scale 50` |

## 안전 규칙과 이유
- **원본은 건드리지 않는다.** 결과는 항상 새 폴더에 저장되고, 결과 폴더가 원본 폴더와 같으면 스크립트가 멈춘다. 사용자가 원본에 덮어쓰라고 해도 먼저 확인한다. 보정은 되돌릴 수 없기 때문이다.
- 폴더 처리 시 이전 `보정결과\` 폴더는 자동으로 건너뛰므로 같은 명령을 다시 실행해도 결과를 또 보정하지 않는다.
- 휴대폰 사진의 회전 정보(EXIF)를 먼저 반영하므로 세로 사진이 눕지 않는다.
- JPG는 품질 95로 저장한다. 투명 PNG를 JPG로 저장할 일은 없지만(확장자 유지), 그런 경우 흰 배경으로 채운다.
- 한 장이 실패해도 나머지는 계속 처리하고 끝에 `n/전체장 처리`를 출력한다.
