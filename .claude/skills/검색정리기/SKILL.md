# 검색정리기

요청: $ARGUMENTS

결과물 두 개를 만든다.
1. `C:\Users\SBS\ai\카드뉴스\자료\<주제>_자료.md`: 근거 자료 (사람이 읽고 검토용)
2. `C:\Users\SBS\ai\카드뉴스\내용\<주제>.json`: 카드 초안 (`카드제작기`가 바로 읽는 형식)

`<주제>`는 한글, 띄어쓰기 없이 (`인공지능 반도체` → `인공지능반도체`). 장수가 없으면 3장.

## 1. 검색
- **오늘 날짜를 기준으로** 최신순 자료를 찾는다. 검색어에 연도·월을 넣는다 (예: `인공지능 반도체 2026년 10월`).
- WebSearch로 찾고, 핵심 수치·사실은 원문 페이지를 직접 열어 확인한다 (WebFetch, 없으면 `web-fetch` 에이전트).
- 출처 우선순위: 정부·공공기관·국제기구 발표 > 주요 언론 > 기업 공식 발표 > 블로그·커뮤니티 (블로그·커뮤니티는 근거로 쓰지 않음).
- **수치는 출처 2곳 이상**에서 맞는지 확인. 1곳뿐이면 `단일 출처`로 표시.
- 각 사실에 **발표·기사 날짜**를 붙인다. 오래된 자료(대략 1년 이상)는 최신 자료로 대체하거나 `기준 시점`을 명시.
- 확인 못 한 것은 쓰지 않거나 `미확인`으로 표시. 지어내지 않는다.

## 2. 자료 md 형식
```markdown
# <주제> 자료 (조사일: YYYY-MM-DD)

## 핵심 요약
- 3줄

## 카드 후보
| # | 윗글(숫자·연도) | 핵심 문장 | 출처 · 날짜 | 검증 |
|---|---|---|---|---|
| 1 | 43% | … | 통계청 · 2026-10-15 | 2곳 확인 |

## 상세 자료
### 1. <소제목>
- 내용 (출처, 날짜)

## 확인 필요
- 엇갈리는 수치, 단일 출처, 미확인 항목

## 출처 URL
- [제목](URL) · 날짜
```
카드 후보는 요청 장수보다 2~3개 많이 뽑아 둔다 (교체용).

## 3. 카드 JSON 초안
카드 후보 중 가장 중요하고 확실한 것을 요청 장수만큼 골라 `내용\<주제>.json`으로 저장한다.

```json
{
  "주제": "인공지능반도체",
  "크기": "1:1",
  "머리말": "인공지능 반도체",
  "바닥글": "2026.10 기준",
  "카드": [
    {
      "윗글": "43%",
      "문장": "AI 반도체 수출이\n1년 새 43% 늘었다.",
      "인물": "산업통상자원부",
      "출처": "2026년 9월 수출입 동향"
    }
  ]
}
```

### 글자 수 기준 (카드 1080px, 맑은 고딕 굵게)
| 칸 | 기준 | 넣을 것 |
|---|---|---|
| `윗글` | 6자 이내 | 핵심 숫자·연도·짧은 키워드 (`43%`, `2026`, `1위`) |
| `문장` | 한 줄 13자 안팎, 2~3줄, `\n`으로 직접 끊기 | 숫자의 의미를 한 문장으로. 끝은 `~다.` |
| `인물` | 14자 이내 | 발표 기관·인물·기업 |
| `출처` | 25자 이내 | 자료 이름·날짜 |
| `바닥글` | 15자 이내 | `2026.10 기준` 같은 기준 시점 |

- 의미 단위로 줄을 끊는다 (`AI 반도체 수출이\n1년 새 43% 늘었다.`). 조사·숫자 단위가 줄 끝에서 갈라지지 않게.
- 카드 하나에 사실 하나. 카드 순서는 `전체 흐름 → 세부 → 전망·의미`.
- 색은 넣지 않는다 (카드제작기의 자동 색 순서 사용). 주제 분위기에 맞는 색이 있으면 JSON 전체 `"색"`으로 지정해도 된다.
- 같은 이름의 JSON이 이미 있으면 덮어쓰기 전에 사용자에게 알린다.

## 4. 보고
- 저장한 두 파일 경로
- 카드 초안 표 (윗글 · 문장 · 출처)
- `확인 필요` 항목이 있으면 함께 알림
- 사용자가 처음부터 "카드까지 만들어"라고 했으면 묻지 않고 `카드제작기` 스킬 순서대로 이어서 만든다. 아니면 초안을 보여주고 끝낸다.
