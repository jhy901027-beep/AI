# 카드제작기

요청: $ARGUMENTS

## 폴더 구조
```
C:\Users\SBS\ai\카드뉴스\
├── 만들기.py           ← 고정 스크립트. 내용 때문에 고치지 않는다
├── 내용\<주제>.json     ← 카드뉴스마다 하나씩
└── 결과\<주제>\<주제>-1.png, <주제>-2.png …
```

## 사용자 지시 형식 해석
사용자는 짧게 지시한다. 아래처럼 해석하고, 빠진 값은 기본값으로 채워 바로 만든다 (묻지 않는다).

| 지시 예 | 해석 |
|---|---|
| `과학발전사 3개 만들어` | 주제=과학발전사, 3장, 1:1, 색 자동 |
| `오늘의 명언 세가지 카드뉴스로` | 주제=오늘의명언(띄어쓰기 없이), 3장 |
| `… 4:5로`, `스토리용` | 크기=4:5 / 스토리·릴스·쇼츠는 9:16 |
| `… 파란색으로`, `전부 바다색` | 모든 카드에 해당 색 (`--색` 또는 JSON 전체 `"색"`) |
| `파일명은 가을명언` | 주제=가을명언 |

- **주제**는 파일명·폴더명에 쓰이므로 한글, 띄어쓰기 없이. 머리말에는 읽기 좋게 띄어 쓴다 (`과학발전사` → `"과학 발전사"`).
- 장수가 없으면 3장.

## 작업 순서
1. **내용 쓰기**: 사실(연도·인물·책 이름·인용)은 정확한 것만 쓴다. 출처가 불확실한 명언은 고르지 않는다. 모르면 웹에서 확인한다.
2. **JSON 저장**: `카드뉴스\내용\<주제>.json` (형식은 아래).
3. **실행**:
   ```powershell
   $env:PYTHONIOENCODING='utf-8'; cd C:\Users\SBS\ai\카드뉴스; python 만들기.py 내용\<주제>.json
   ```
   옵션: `--크기 1:1|4:5|9:16`, `--주제 <이름>`, `--색 <색이름>` (JSON보다 우선)
4. **이미지 확인 (필수)**: 만든 PNG를 **모두 Read로 직접 열어** 본다.
   - 낱말이 어색하게 끊기면(`입 / 안에`) → 문장에 `\n`을 넣어 끊는 위치를 직접 정한다
   - 줄이 너무 많아 답답하면 → 문장을 줄이거나 `\n` 위치 조정
   - 고친 뒤 다시 실행하고 다시 확인
5. **보고**: 카드별 표(파일 · 핵심 내용 · 인물/연도 · 색)와 결과 폴더 경로. 검증 안 한 사실이 있으면 그렇게 말한다.

## JSON 형식
```json
{
  "주제": "과학발전사",
  "크기": "1:1",
  "머리말": "과학 발전사",
  "바닥글": "과학이 세상을 바꾼 순간",
  "색": "바다",
  "색순서": ["노을", "남색", "초록"],
  "카드": [
    {
      "윗글": "1543",
      "문장": "태양이 우주의 중심에 있고\n지구가 그 주위를 돈다.",
      "인물": "니콜라우스 코페르니쿠스",
      "출처": "《천구의 회전에 관하여》 · 지동설",
      "색": "노을"
    }
  ]
}
```
| 키 | 필수 | 설명 |
|---|---|---|
| `주제` | O | 파일명 `<주제>-N.png`, 결과 폴더명 |
| `카드[].문장` | O | 본문. `\n`으로 줄바꿈 위치 지정. 한 카드 2~3줄 권장 |
| `크기` | | `1:1`(기본) · `4:5` · `9:16` |
| `머리말` | | 왼쪽 위 제목 (없으면 주제) |
| `바닥글` | | 맨 아래 작은 글 (날짜, 한 줄 문구 등). 없으면 생략 |
| `색` / `색순서` | | 전체 공통 색 / 카드별 색을 안 정했을 때 돌아가며 쓸 순서 |
| `카드[].윗글` | | 본문 위 큰 글자 (연도·숫자·키워드). 없으면 따옴표 “ 표시 |
| `카드[].인물`, `카드[].출처` | | 구분선 아래 이름과 작은 설명. 둘 다 없으면 구분선도 생략 |
| `카드[].색` | | 이 카드만의 색 |

- **색 우선순위**: `--색` > 카드 `"색"` > JSON 전체 `"색"` > `색순서`(없으면 기본 순서) 차례대로
- **윗글 쓰는 법**: 명언류 → 비워서 따옴표, 역사·사건 → 연도, 통계·정보 → 핵심 숫자
- 이웃한 카드는 서로 다른 색으로 고른다.

## 만들기.py 구조 (수정이 필요할 때만)
| 부분 | 역할 |
|---|---|
| `크기목록` | 크기 이름 → (가로, 세로). 새 크기는 여기에 추가 |
| `색상목록` | 색 이름 → ((위 RGB), (아래 RGB)) 그라데이션. 새 색은 여기에 한 줄 추가 |
| `기본색순서` | 색 미지정 시 돌아가며 쓰는 순서 |
| `그라데이션()` | 위→아래 배경 |
| `줄나누기()` | `\n` 우선, 넘치면 띄어쓰기 → 글자 단위로 줄바꿈 |
| `카드만들기()` | 카드 1장 그리기. `s = 가로/1080` 배율로 모든 크기·여백을 곱해 크기와 무관하게 같은 비율 유지. 본문 글자는 72px부터 줄이 넘치지 않을 때까지 2px씩 줄임. 윗글/따옴표 + 본문 + 인물·출처를 한 덩어리로 세로 가운데 정렬 |
| `main()` | 인자 처리 → 색 결정 → `결과\<주제>\<주제>-N.png` 저장 |

현재 색: 주황 · 파랑 · 보라 · 초록 · 분홍 · 노을 · 바다 · 남색 · 숲 · 회색 (목록에 없는 색을 요청받으면 `색상목록`에 추가한 뒤 사용)
글꼴: 맑은 고딕 (`C:/Windows/Fonts/malgun.ttf`, 굵게 `malgunbd.ttf`)

## 규칙
- 새 파일·폴더 이름은 한글.
- 내용만 바뀌는 요청에 `만들기.py`를 고치지 않는다. 디자인·기능 변경 요청일 때만 고치고, 고친 뒤에는 기존 `내용\*.json`이 여전히 잘 나오는지 하나 이상 다시 만들어 확인한다.
- 시험으로 만든 결과 폴더는 확인 후 지운다.
